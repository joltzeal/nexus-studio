# 应用代理

## 当前实现

设置 → 应用代理支持“不代理”“系统代理”“手动代理”，保存在本机 `nexus.sqlite`。
手动模式接受不含用户名与密码的 `http://`、`https://` 或 `socks5://` 地址，
必须包含端口，例如 `socks5://127.0.0.1:7890`。读取或保存失败会显示错误。
初次安装默认不代理；修改配置后已启动的插件进程被停止并由宿主重新拉起。

Rust 插件商店和应用更新请求使用显式配置的 reqwest 客户端，不沿用进程环境中的代理变量；
浏览器适配器和插件子进程在启动时注入代理预加载模块，将 Node `fetch` 通过
HTTP(S) 或 SOCKS5 转发。代理连接失败时这些请求报错，不回退到直连。
激活码校验与内核准备也使用此预加载模块。已启动的浏览器适配器不会热切换，
需要关闭该窗口再启动。窗口自身的浏览器代理仍由窗口配置决定，应用代理
不会修改 Profile 的浏览器流量。

SOCKS5 连接目的端口按请求协议补全：Undici 对默认端口传入空字符串时，
HTTPS 使用 443、HTTP 使用 80；显式非默认端口保持不变。
2026-10-24 修复了此前将空字符串转换成 0 导致 HTTPS 校验、下载和插件请求被重置的问题。
该修复不改变所选代理，也不增加失败后的直连回退。

窗口的“通过代理 IP 匹配时区、语言和 WebRTC IP”通过窗口自身代理访问
ipwho.is，失败后尝试 IP.SB；使用独立 dispatcher，不继承这里的应用代理。
不再下载或读取 GeoIP 数据库，也不要求用户配置接口密钥。
每个服务最多等待 5 秒，失败不会切成直连；手工时区和语言优先。
这类请求属于浏览器启动适配器，代理池插件的独立检测和评分保持原有协议。
实现与失败分类见[浏览器接入](05-browser-integration.md)。

## 系统代理边界

macOS 从 `scutil --proxy` 读取 SOCKS、HTTPS 或 HTTP 的静态配置；
Windows 从当前用户的 Internet Settings 读取静态代理。
自动配置脚本 PAC 不受支持；检测到 PAC 时拒绝保存或请求，并提示改用手动代理。
如果系统没有设置代理，系统代理模式按系统现状直连。系统代理改变后，
新启动的子进程使用新配置；插件商店每次请求重新读取。

插件为受信任的独立 Node 进程。当前统一代理覆盖 Node `fetch`、商店和应用更新的
reqwest；插件自行创建的原始套接字、特定 HTTP 客户端以及浏览器页面流量
不受这一层约束。代理池插件自身的代理连通性检测会连接指定端点，
不能将应用代理当成插件进程的网络沙箱。

## 应用更新

关于页通过 `app_update_check` 原生命令检查更新。该入口读取同一份
`NetworkProxyStore`，检查清单与后续更新包下载均由 Tauri updater 执行：
不代理模式清除自动继承代理；系统模式解析当前静态配置，没有代理时明确直连；
手动模式使用所填 HTTP(S) 或 SOCKS5 地址。显式代理也不因环境中的
`NO_PROXY` 绕过。代理连接失败不会重试直连，设置损坏或读取失败不会默认直连。

每次检查更新会重新读取设置、解析系统代理，并将结果保留到该更新的下载请求。
检查以后修改代理或系统设置，需要重新检查更新才能使用新路由。
检查最多等待 30 秒，包下载最多等待 15 分钟。包签名仍由 Tauri 按发行配置的
固定公钥校验，代理不会关闭 TLS 或验签。关于页区分设置读取、代理解析、
更新源无清单、清单格式、平台缺失、网络与超时错误，不展示原始内部诊断。

旧安装包曾直接调用 updater 默认 `check()`，没有接入应用代理设置，
且其更新源指向不存在的 `joltzeal/nexus-studio-updates`。
修改设置无法修复旧包的端点；迁移边界见[桌面发行与更新](20-desktop-release-and-updates.md)。

## 验证

在桌面设置中保存手动 SOCKS5 地址，刷新插件商店或使用发起 `fetch` 的插件；
停止本机代理后同一请求应报连接错误。用系统代理模式重复检查，
随后切换“不代理”确认请求恢复正常。分别在 macOS 和 Windows 安装包上验证。
更新链路还需检查“关于 → 检查更新”与包下载，确认两者均使用所选路由；
停止代理后检查或下载应失败，不能因源站本身可直连而成功。
原生单元测试使用本地 HTTP/SOCKS5 服务验证转发、显式直连、代理失败阻断，
并覆盖代理数据库损坏与无效已存配置。它们不代替 Windows 安装、
macOS 覆盖更新、系统 PAC 和真实第三方代理的整机验证。
