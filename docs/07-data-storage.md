# 演示存储与长期数据规划

## 当前存储事实

旧版演示存储仍留在前端 localStorage，但桌面窗口页不再从中读取窗口。
当前页面的分组、外观和工作区设置仍走 localStorage；真实窗口写入原生 Profile 目录。
窗口详情展示原生配置，不读取 Cookie 或账号内容，也不会启动会话。
搜索、分组筛选及编辑/预览 Dialog 的开关为当前组件状态，不代表浏览器会话恢复。
此前 Rust SQLite 偏好方案退出本轮范围，已移除对应业务实现。
原生数据由 Rust 单独写入应用数据目录：CloakBrowser 授权在 `nexus.sqlite`，
插件登记表与安装副本在 `plugins/`，插件自己的密码在 `plugins/storage/<id>/secrets.json`（明文）。
Profile 记录和浏览器数据位于 `profiles/<id>/`；这些目录不与 localStorage 同步，详见[插件宿主](17-plugin-host.md)。

## 存储边界

localStorage 按来源隔离，浏览器预览和 Tauri WebView 不自动共享。
切换浏览器、来源或运行模式后，不承诺读取同一份演示数据。
当前本地演示保存不能描述为数据库写入、云同步或系统级安全存储。
清理站点数据、隐私模式及浏览器限制可能影响保存与保留。
页面应准确说明未连接状态，不能引导用户存入真实账号、令牌或代理密码。
当前不提供真实导入、备份、跨设备同步或 profile 迁移承诺。

## 前端组织约定

通过集中适配层读取和写入 localStorage，避免页面散落序列化逻辑。
键名使用项目命名空间，数据带可识别的格式版本或等效兼容处理。
历史演示窗口与分组使用 `nexus.demo.workspace.v1`，设置使用 `nexus.preview.preferences.v1`；桌面原生窗口不读取前者。
对象字段与默认样例以主线实现为准，文档不构造第二套 schema。
持久化读取需校验结构，不把任意 JSON 直接当成严格类型对象。
空白安装不创建样例窗口或分组；刷新不得覆盖用户修改。
旧分组与原生窗口尚无关联，不能展示成真实窗口分组。
主题与工作区设置保持职责独立，恢复外观不隐含删除全部窗口。

## 保存与错误语义

只有 localStorage 写入成功，才能提示本地演示已保存。
序列化、配额、访问拒绝或数据损坏需得到明确且可恢复的处理。
保存失败保留可恢复输入，不把失败吞掉后继续显示成功。
如果实现内存临时状态，必须清楚表明尚未保存，不能冒充持久化。
读取不兼容数据时说明恢复路径，不静默宣称已迁移或永久保留。
重置是显式操作，应说明影响范围，避免以清空全部数据解决任意错误。
浏览器重载后恢复演示状态，只证明本地演示持久化。

## Rust 与 SQLite

SQLite 由 Rust 唯一所有者管理；当前仅 CloakBrowser 授权表已接入。
React、Node.js 适配器和插件通过受控接口进入，不直接打开业务库。
数据库位于平台应用数据目录，不依赖源码、当前工作目录或安装资源目录。
输入在边界校验，事务成功后才返回真实业务保存结果。
迁移集中管理，版本单调演进，失败保持可恢复状态。
不兼容版本应明确拒绝，不能静默重建数据库或覆盖用户数据。
表、列、索引随真实功能添加，不预建尚未使用的环境或账号 schema。

## 演示数据与真实业务切换

未来启用原生存储时应显式选择数据来源，不把演示数据自动认作真实业务。
如需迁移，另行设计格式映射、用户可理解的范围、失败恢复及验证。
Rust 业务失败时禁止静默切回演示数据并继续显示真实业务成功。
原生接入前不要求演示页面实现空数据库接口或伪造跨语言成功响应。
浏览器 profile 与业务数据库仍有不同生命周期，不能混为同一存储层。

## 密钥规则

当前 CloakBrowser 授权密钥存储在应用数据目录 `nexus.sqlite`，数据库文件未加密，依赖当前 OS 用户权限。
Unix 文件权限限制为当前用户；Windows 依赖应用数据目录 ACL。密钥只供 Rust 核心授权和浏览器启动流程读取，
前端只收到状态元数据，不提供读密钥接口，也不暴露给插件。
代理凭据、API secret 与其他访问令牌仍不得明文写入业务数据库；未来需单独采用
插件私有目录内的明文文件，并在界面与文档中如实说明。
授权缺失、失效和解析失败应具有明确错误，日志不回显敏感值。
演示夹具、源码和浏览器存储均不得收集或放入真实凭据。
终端用户不依赖 `.env` 文件配置产品业务。

## 验证范围

当前验证读取、修改、刷新恢复、关系一致性、重置范围与存储失败反馈。
区分预览来源与桌面来源，不以单一环境结果推定数据共享。
未来再验证其他业务表的 SQLite 迁移与事务失败；原生 Profile 重启恢复有开发环境测试，但授权流程仍待真实密钥验证。
