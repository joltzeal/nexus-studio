# AI 生图 EXIF 后置模板

## 范围

生成弹窗提供可选“自定义相机模板”。启用时，将用户填写的模板随生成任务快照持久化；
新上传的本地和远程参考图也按上传当时的模板处理。PNG/JPEG/WebP 解码后合成白底，
统一转码为 JPEG，写入所选 EXIF 字段；相机、镜头、时间、曝光、分辨率、软件等字段均可编辑。
相机信息是用户提供的元数据，不证明图片由该设备实际拍摄，也不保证平台如何识别。
不写 GPS；像素已按来源方向转正，所以方向只允许 top-left，避免双重旋转。

模板在桌面端 localStorage 保存开关与表单，已接受任务保存独立快照，重试沿用原快照。
模板关闭时维持原有图片字节和格式，不修改旧记录；切换模板不会重写已上传参考图。
上传阶段结束后才使用任务快照生成，因此用户在上传和生成之间改动模板时，
已上传的参考图与成片可能使用不同字段，界面明确提醒重新上传。
格式/尺寸无效或编解码失败时报告错误，不将未经处理的成片标记为成功。

内部图片仍由 UUID 作稳定索引，新文件存储为 `images/<UUID>/IMG_####.<ext>`；
生成记录保存随机文件名，导出到系统下载目录的 `Raccoon AI/` 时使用相同名称与字节。
同名导出文件不覆盖，不同内容追加序号；旧的平铺 UUID 文件保持可读取。
仅启用模板的输出必须是 `.jpg`；其他新文件也使用随机显示名，但保留原扩展名。

插件包带四个纯 WASM 编解码资源，由插件本地打包工具作为资源装入安装包。
不要求用户安装第三方图片工具或原生扩展；桌面应用和私有插件须配套更新。

## 验证边界

本地图片处理、任务快照、持久化、导出、安装包内实际上传转码以受控图片验证；
真实生图服务商、Windows 安装、UI 中实际照片的视觉效果和平台识别结果未验收。
