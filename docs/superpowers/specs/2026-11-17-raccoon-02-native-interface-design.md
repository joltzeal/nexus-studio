# Raccoon 0.2：桌面界面与主题重构方案

状态：工作台重写的界面方案，侧栏与窗口列表结构已开始实施，设置与跨平台验收尚未完成。参考用户提供的 AliasMode 窗口截图及文档式侧栏截图；
只借鉴信息层级、区域分工和表格密度，不复制品牌或业务入口。
视觉审视依照 unslop（Damir Sokolovsky，CC BY 4.0）的方法。

## 设计方向

- **产品**：跨指纹浏览器的窗口、账号插件与任务工作台。
- **性格**：安静、紧凑、可靠。
- **语境**：桌面工具的侧边导航、文件列表和检查面板。
- **焦点**：正在运行的窗口状态、需要处理的连接与任务；颜色只提示可操作状态。
- **识别点**：提供方选择与窗口运行状态靠在一起，能看清每个窗口属于哪个接入。

截图所示的左侧常用动作、清楚的当前位置、右侧完整列表面板和底部分页
是本方案的直接参考。Raccoon 保留已有纸白与钴蓝，不增加商业化悬浮按钮、
无来源的统计信息或 AliasMode 专属功能。

这次是结构问题，不能只换色值或给网页叠一层系统阴影解决。

## 页面结构

```text
系统窗口与原生菜单
├── 固定侧栏：品牌 / 浏览器类型切换（即 space）/ 窗口 / 分组 / 动态插件 / 设置
└── 工作区
    ├── 顶栏：当前位置、返回或上下文动作、连接状态
    └── 页面容器
        ├── 窗口：提供方选择 / 搜索筛选 / 表格 / 分页
        ├── 插件：页面工具栏 / 插件内容 / 底部反馈
        └── 设置：分区导航 / 当前设置页
```

窗口管理按照参考截图使用右侧满宽表格工作区：白色侧栏和顶栏、略深一阶
的工作区底色、一个承载筛选/表格/分页的白色面板。页面外框留 12–16px 缓冲，
面板使用细分隔线和 8–12px 圆角；不对表格逐行套卡片。侧栏初始
宽约 216–240px，允许折叠，不把新增插件固定塞成几十个平铺导航项。
页面主标题 18–20px，正文 13–14px，表头 12px；控件高 30–32px，
行高约 40–44px，按内容增加高度时须有上限与弹层。保留现有本地字体
资源，减少不必要的 700/800 粗字重与小字号负字距。所有尺寸由局部
页面密度 token 管理，不能在业务组件里再叠任意 `margin` 修补滚动。

窗口页：侧栏切换当前浏览器 space，顶栏明确当前提供方与接入状态；不再额外
显示与 space 重复的提供方 Tabs。工具栏按“分组、搜索、更多筛选 /
刷新、显示列、创建”归组。选择行后在相同位置替换为选中数与批量操作；
不长期占据空闲空间。把运行中、未知、缺少连接等状态写在行内，状态颜色
配合文字或图标，不以绿色点代表所有成功。已启用的浏览器提供方可切换，
未连接时显示该提供方的连接入口。列表内滚动，表头保持可见，分页和总数
贴在面板底部；列表区域占满剩余高度，空列表允许自然留白，底栏不会遮盖
最后一行。窄窗口保留可发现的局部横向滚动，并让操作始终可触达。

插件页统一页面抬头、工具栏、内容和反馈位置。插件仍拥有自己的业务表格和
筛选，但共享边距、滚动容器、空状态、错误提示、弹窗尺度与操作按钮优先级；
插件之间跳转保留已有筛选状态和返回路径。工作区壳不出现 SIM8 或其他插件
专属提醒，提醒只在关联内容的页面出现。

设置采用固定分类列表，选择后只展示一类内容。浏览器接入默认展示 AdsPower
和比特浏览器的发现、连接和状态；实验室容纳 CloakBrowser、AliasMode
Chromium 的开关、激活或发行版本、已安装清单及手动下载。开启和下载是两次
明确操作。较长的内核列表只在内容面板滚动；任务进度和失败原因原位可见。

## 桌面平台适配

使用系统窗口装饰和原生窗口控件；macOS 保留交通灯位置及系统菜单习惯，
Windows 保留最小化、最大化与关闭按钮及系统标题栏行为。初期不采用跨平台
自绘无边框标题栏；只有验证拖动、双击最大化、窗口菜单、焦点、DPI、
多显示器及辅助功能都正确后才考虑更深的标题栏融合。

共用页面信息结构，分别适配安全区、标题栏高度、滚动条呈现、菜单项与快捷键
标注：macOS 使用 Command，Windows 使用 Ctrl；搜索、刷新、创建、返回、
关闭弹窗都要能通过键盘完成。Dialog、Popover 在缩放和小窗口下保持边界，
焦点可回到触发位置。系统主题优先，允许手动覆盖浅色或深色；不通过浏览器
用户代理猜测系统，平台差异由 Tauri 原生窗口信息决定。

原生感以系统控件、菜单、滚动和交互为准；不依赖毛玻璃、厚阴影、悬浮动画
或伪装系统截图。页面的业务数据与服务状态不能伪造。

## 主题和状态

沿用 `App.css` 的 `background / foreground / card / primary / border / muted`
等 shadcn 语义变量，纸白背景、安静的灰阶、钴蓝主操作。蓝色只用于当前选择、
主操作与可访问焦点；封禁、失败、运行中分别有明确的语义状态 token。
图标沿用 Lucide，同一上下文统一 16px；不用 emoji、渐变文字和炫光。
悬停只改变背景或边框，加载仅在实际请求上显示，不为静态页面加循环动效。
系统减少动态效果优先。

## 实施与验收

先确立应用壳和单一滚动所有权，再重写窗口列表、设置和插件容器，最后统一
主题 token、文字、图标和交互动效。旧页面只作为业务行为参考；按 0.2 契约
重建窗口关系、真实过滤、弹窗与插件跳转，不复制 0.1 的页面状态流。
用空数据、100 个窗口、
长名称、多插件、未知连接、下载失败等状态检查布局。

分别验收 macOS 和 Windows 的初次安装、最小尺寸、多显示器缩放、系统菜单
和键盘流程；测试表格列溢出、滚到底时的底部间距、分页固定与可访问性。
这是一份实施方案，当前没有新页面或两平台视觉验收结果。
