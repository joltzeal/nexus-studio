# 地址生成器 desktop-v2 升级

**Goal:** 将地址生成器迁入 desktop-v2，仅保留 Google Maps 地图选点，移除 OpenStreetMap/Overpass 生成路径。

**Spec:** `2026-11-19-raccoon-plugin-pages-desktop-v2-design.md`，以用户本次“直接地图选点”要求替代其中公开地址生成部分。

**Architecture:** 页面使用 ShardX UI Kit、现有插件目录门禁和 `callPlugin`。地图 Key 通过主程序 `VITE_GOOGLE_MAPS_API_KEY` 构建注入，不由用户填写，也不发给插件。插件持有地址私有文件；地图 SDK 在 WebView 渲染和解析选点。应用不访问其他插件私有文件。

**Direction:** 面向账号资料整理的地图工具；紧凑、准确、安静。地图承载颜色，外围沿用应用主题。右侧显示完整地址、坐标及位置精度，已保存地址使用原有列表组件。

## 约束与验收

- 无 0.1 页面适配、旧 IPC 回退或 OSM 查询；已保存数据不删除。
- 地图缺 Key、授权失败、地址缺少门牌/邮编、国家不符均给明确反馈，不编造地址。
- firstname、lastname、username 以及每个地址/坐标字段均可独立复制，另可复制完整地址。
- 快速连续选点、切换城市/主题、离开页面后丢弃过期结果并解除监听。
- 保存确认来自插件回读；写入失败保留选点。重复地点使用首次保存的资料。
- 关联账号只读取无凭据的地址目标 RPC，明确确认替换，传入预期旧地址 ID。
- 插件进程不再申请 Overpass 网络域名。v2 CSP 单独声明地图所需来源。
- 用户在本轮后续明确要求停止插件 build 和图像验证；该要求之后只执行源码测试、lint 和无产物类型检查。

## 实施顺序

- [x] 插件移除 Overpass 方法、服务及依赖，升级 manifest 并验证选点/持久化回归。
- [x] 添加严格响应解析、RPC 适配、能力门禁及选点生命周期测试。
- [x] 实现地图、逐字段复制、保存列表、构建 Key 注入及账号关联，注册 lazy 页面。
- [x] 核对 CSP，执行定向测试、无产物类型检查与 lint；后续禁止 build 前已经执行过一次插件单独编译，未再次执行。

实际检查与原生/真实地图验收边界见 `docs/09-quality-and-testing.md`。Google SDK 的受控替身检查不证明真实授权、计费请求或原生 WebView 地图连通。
