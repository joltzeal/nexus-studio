# VInted helper 面单提取实施计划

**目标：** 将地址生成器显示名称改为 VInted helper，保留地图选点、资料生成、地址库与账号关联，新增单个或多个 PDF 面单的本地 A6 提取与下载。

**实现：** 沿用 `studio.address-generator` 的安装身份、私有地址文件和 `address.generator` 权限，增加公开 `vinted.labels.*` 契约。Node Worker 内使用 PDFium WASM 测量墨迹、pdf-lib 重组原始矢量；不引入 Python、服务端、OCR 或真实面单上传到第三方。

**参考：** `nexus-cart/apps/api/backend/app/vinted/labels/extractor.py`：仅检查实际调用的 Form XObject，以 FROM、TO、TRACKING 识别面单，多候选拒绝，自动隔离失败标记保留整页；支持手动裁剪、旋转和 CropBox，输出 105 × 148 mm A6，默认边距 3 mm。

## 任务

- [x] 公共契约与提取器：严格参数、页数/尺寸/字节限制；合成 PDF 验证 A6 尺寸、矢量文本、隔离、整页回退、旋转、手动裁剪、空白/损坏/多候选拒绝。
- [x] 插件传输与任务：192 KiB 分块，10 MiB/文件、50 页/文件，最多 20 个临时任务；串行 Worker、180 秒超时、关闭/取消/过期释放；SHA-256 下载校验；worker 与 WASM 资源显式随插件打包。
- [x] desktop-v2：新增面单工具、批量文件选择、边距和可选裁剪、失败重试/下载；独立能力门禁，不受地图 Key 和目录加载失败影响。交互按下方修订采用上传即处理。
- [x] 名称与文档：manifest、专用页、目录说明更新显示名称，安装 ID 和历史地址不变；质量记录只填写实际结果。
- [x] 原生下载：通用 `plugin_pdf_export` 在 Rust 校验大小、PDF 标识及 SHA-256，使用系统另存为与同目录临时文件原子写入；取消不显示成功。Rust 源码仅 rustfmt，编译和测试留待 CI。
- [x] 检查：直接 Vitest、无产物 TypeScript、ESLint、Prettier、diff 检查；不执行插件/应用 build、Rust、截图、图像验证、提交或发布。

## 重点边界

- 原件不覆盖；一页失败使该文件失败，批量其他文件继续；重试使用新任务。
- 无法自动识别不能声称已隔离，结果保留整页回退提示，用户可指定毫米裁剪区重试。
- 插件会话只在本次进程内暂存，前端读取结果后立即释放，30 分钟过期作为兜底；页面缓存保留到离开 helper，下载到本机由用户点击发起。
- 传输会话校验 ID、顺序、偏移、完整大小和哈希；损坏响应不能作为下载文件。
- 用户最新约束优先，不创建 worktree、不提交、不运行构建或视觉验证。
