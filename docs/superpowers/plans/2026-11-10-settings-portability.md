# 接入简化与配置迁移

## 目标

- 窗口首页只显示实际业务提醒，不显示插件升级或可用性宣传。
- 外部浏览器使用默认本机 API 地址，一次操作完成保存、检测、确认和启用。
  保留连接与已有窗口的身份绑定，切换官方账户仍需新建连接。
- 设置提供 JSON 配置导出、文件预览、选择性导入；各插件通过统一方法管理自己的配置。

## 实施顺序

1. 移除首页插件状态提示，合并浏览器连接流程并验证失败重试与重复提交。
2. 定义插件 `configuration.export / validate / import`，配置与业务记录分开。
   接入 AI 服务商、SIM8、地址生成器、代理池和商品监控的配置。
3. 增加设置文件选择与读写命令，前端负责版本校验、导入预览、逐项结果和失败重试。
   包括外观/工作区偏好、应用代理，以及受支持的插件配置。
4. 更新数据、页面和插件开发文档；运行直接单元测试、静态检查和格式检查。

## 约束与验证

配置文件包含使用者选择导出的明文凭据，不保存激活验证结果、运行中任务、浏览器
目录、Cookie 或机器路径；已有窗口转移功能保持独立。
导入前先完成所选插件的校验；文件中不存在的部分不修改。
单个配置项落盘成功后才记录成功，跨插件失败必须展示实际结果，不能声称整包原子写入。
不运行本地构建、打包或 Rust 编译；原生命令执行与平台文件对话框留待桌面/CI 验证。

## 实施状态

- 首页插件状态提示已移除，保留实际号码提醒。
- 接入界面已合并操作并提供默认地址；不修改既有连接的窗口身份。
- 五个有独立配置的插件已接入统一配置协议，设置支持预览、选择性恢复和失败重试。
- 模块文档已同步，直接测试、无产出静态类型、ESLint 和 Rust 格式检查通过。
  实际结果及未执行的原生检查记录于 `docs/09-quality-and-testing.md`。
