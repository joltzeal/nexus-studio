# 地址保存与账号关联实施计划

按用户要求直接实施，沿用现有插件私有存储、RPC 和 shadcn 页面，不引入服务。

## 数据与交互

地址生成插件维护已保存地址；账号池维护独立的完整地址快照，二者使用地址
profile ID 关联展示。每个账号最多一个地址，同一地址允许多个账号使用。
账号地址单独更新，不能重新保存整个账号而覆盖并行的号码、状态或密码修改。
替换和解除关联携带上次看到的地址 ID，已变化时提示刷新。
移除地址收藏不清空账号上的快照；删除账号自然清除账号自身地址。

地图选点与公开查询共用城市目录，补充美国主要城市中心。只增加导航中心，
不会伪造地图反查结果或补齐缺失门牌。

页面入口随主应用编译，需同时发布配套主应用和地址、账号池插件；
插件构建只在远端执行，下载 CI 产物后核验启动，再合并发布到 R2。
不得覆盖已有同版本包或用局部目录替换线上完整商店。
