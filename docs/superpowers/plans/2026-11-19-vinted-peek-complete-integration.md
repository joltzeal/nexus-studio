# Vinted Peek 完整交互接入

用户要求衣柜快照直接展示，补齐 v1 的账号分配、SIM8 号码分配、短信与邮箱取码及语音播报，并按账号状态为图标着色。用户明确要求不运行 dev。

## 实施边界

- Vinted 的字段、状态映射、关联检查、SIM8/邮箱选择与验证码规则保留在插件。
- 宿主提供通用声明式跨插件只读服务转发、后台任务调度、通知与数字语音。
- 服务请求只可使用 manifest 的 UI services 声明，核对双方授权、方法、安装和进程身份。
- 新后台任务使用独立原生入口核对插件与 Profile 连接，面板关闭及页面切换继续等待，插件变化终止。
- 等待按账号和通道去重，5 秒时点、5 分钟截止，取消和资料变化后忽略迟到结果。
- 图标通过批量的插件状态投影获得语义颜色，宿主不解释 Vinted 状态。
- 不运行 dev、应用构建、Rust 编译或真实接码请求，不提交或发布。
