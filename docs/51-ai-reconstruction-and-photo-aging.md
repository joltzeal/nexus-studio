# 商品场景重建与做旧程度

AI 生图以商品参考图为身份依据，理解用途、风格、可见设计与不确定项，再组织适合商品的新场景。原图的背景、摆件、光线和机位不作为需要复刻的模板。

## 独立做旧选项

“做旧程度”控制环境的生活痕迹和手机拍摄的不完美感，不改变商品成色：

| 档位       | 请求值     | 场景与拍摄要求                                                         |
| ---------- | ---------- | ---------------------------------------------------------------------- |
| 无         | `none`     | 不额外增加杂物和环境旧化，仍是普通手机拍摄，保留真实商品痕迹           |
| 轻微       | `light`    | 少量日常物件、轻微使用痕迹、略偏的构图与自然光差异                     |
| 适中，默认 | `moderate` | 明显有人生活的房间、若干不成套杂物、使用过的台面、随手构图和不均匀光线 |
| 明显       | `heavy`    | 更明显的日常杂乱和环境使用痕迹、普通室内曝光瑕疵，所需商品细节仍能看清 |

四档均排除广告棚拍、刻意精致的摆拍、电影式破败和过度模糊。背景物品不能遮住需要展示的商品部分或暗示随商品赠送。该选项优先于预设中“极简台面”等背景整理要求。

任何档位都不授权新增商品划痕、污渍、褪色、破损、缺件或修补。已有的明确磨损仍应保留。做旧印花属于设计，不能被自动认定为实物损伤。

各档位共用精简的个人卖家手机随拍基底：合理的家庭摆放、不完美构图、普通室内光、
轻微噪声和白平衡误差；排除棚拍、商业陈列、电影调色和人工虚化。
原始英文提示词中的 `[PRODUCT]` 在已识别商品的生成阶段替换为识别出的
商品名称；尚未识别时使用通用的 `item being listed`。商品大小、用途、
所选场景与特写视角可覆盖默认台面、距离和俯拍角度。
商品上只有参考图独立证实的痕迹才能呈现，不能因选择较高档位新增损伤。

## 识图与重建

识图输出用于约束“商品是什么、适合怎样的生活场景、哪些事实仍不确定”，而非把原照片写成详细的画面描述后要求照搬：

1. 确认可见的轮廓、颜色、图案、文字和风格。
2. 普通生成根据商品类型和新任务 ID 选择日常家庭场景：地垫平铺在不同房间的地面；铁皮画/帆布画可平放于床单、桌面或地面，也可靠墙或摆在矮凳上；其他小件使用桌面、床单、置物架、地面或椅面。同一任务重试沿用已保存的实际提示词；不同新任务可能选择不同场景。批次多图会给每张图不同场景与机位指令，实际采纳程度取决于生图服务商。用户明确选择的预设优先。
3. 重新组织背景和日常物件，保留商品身份与设计。
4. 应用独立的做旧档位，再组合用户约束、场景预设和多视角要求。
5. 不猜测不可见的背面、内部结构、材质、尺寸或来源。

直接改图仍使用参考图片；这次改变的是模型理解与提示词约束，不会把原商品替换为只有文字描述的无参考生成。

## 卖家标题与描述

标题是简短的商品识别信息，描述使用自然、简洁的英文二手卖家口吻。不要写“图片展示了……”、镜头、光线、背景或构图，也避免广告套话和关键词堆叠。

仅使用用户已确认资料与明确的商品证据。不编造使用年限、购买经历、出售原因、品牌真实性、无烟无宠、功能正常、材料或成色等级。成片中的合成痕迹不是实物磨损的证明，成片识图同样遵守此规则。

模型仍只有识图与生图两类；本次没有增加文案模型。提示词、标题、描述、理由和多视角说明继续使用英文。

## 保存与重试

`image.generate`、`image.plans.create`、`image.providers.testImage` 接受：

```ts
agingLevel?: 'none' | 'light' | 'moderate' | 'heavy'
```

普通新任务缺省为 `moderate`。使用已完成方案时，省略该值会继承方案档位；明确提交不同档位会在生图前拒绝，要求重新规划。

更改档位会使当前规划上下文失效，避免旧方案覆盖新选择。参数随队列、批次、记录详情和历史摘要保存，多视角失败重试沿用原任务快照并保留成功图片。旧历史没有该字段时保持未知，不把默认值伪装成当时的选择。

模型请求前验证枚举和英文输入。若接受响应丢失了明确提交的档位，界面提示到历史核对，不通过去掉参数自动再次提交。

普通识图不再让模型输出完整场景 prompt；它只输出商品事实、英文卖家标题描述与必要的英文用户要求翻译。图片生成成功后，应用级待办按记录 ID 将整组成片和文案幂等导入商品库草稿；弹窗关闭或应用重启不取消待办。插件不可用或复制失败保留待办，提示手动重试入库，不重新生图；已提交但登记失败时显示记录 ID，供用户从历史手动导入。只有参考图任务自动入库，纯文生图和服务商测试不入库。

完整提示词实现保留在本机 `plugins/ai-image/src/domain/photo-realism.ts`、`automatic-scene.ts` 与 `services/openai.ts`，不随主应用仓库提交。受控测试验证请求和状态传递，实际照片质感及卖家文案仍需要真实服务商生成结果验收。
