# 主题与交互规范

## 当前设计方向

最新用户要求采用现代 B 端后台风格，避免古典后台样式。该要求取代此前的 C 端插画方向。
保留已确认的纸白与钴蓝色系，取消营销式大标题、叠放窗口插画、装饰贴纸和大面积彩色封面。
界面使用紧凑侧栏、轻量顶栏、搜索筛选工具栏与窗口列表。
不添加无业务意义的统计卡、虚构图表或复杂多级菜单。
此前 [Paper Play 概念图](design/paper-play-concept.png) 仅作为历史色彩参考，不再作为布局验收基准。

## 色彩与主题

所有 token 集中在 `apps/desktop/src/App.css`，组件使用语义变量。
默认背景 `#F8F7F3`，正文 `#202024`，卡片白色，主色 `#3555F6`。
边框 `#E3E3EA`，辅助文字 `#666878`，选中背景 `#E9EDFF`。
强调色提供钴蓝、珊瑚、石墨、鸢尾；主操作色采用适合文字阅读的深色变体。
状态色与品牌强调色分离，未连接状态使用中性样式，不暗示环境已启动。
深色使用根 `.dark` 与相同 token。默认浅色，也可跟随系统。
颜色不能成为状态的唯一表达方式；同时提供文字、选中态与焦点。

## 信息架构

侧栏包含工作区信息、窗口管理、分组管理、插件中心、代理池、地址生成器、共享货源、应用设置。
顶栏显示当前导航路径、主题切换。
窗口页：页面标题和创建操作，分组筛选与搜索，环境表格，数量说明。
表格包含窗口名称及备注、平台、所属分组、代理方式、状态与增删改查操作。
分组页采用轻量卡片，显示名称、数量和窗口摘要，提供新建、重命名和查看。
插件页按能力展示，不伪装成真实插件商店，不展示虚构下载量或评分。
应用设置包含外观、工作区和关于，使用普通设置表单，无装饰插画。

## 字体、尺度与密度

本地字体：Manrope Variable、Noto Sans SC Variable，等宽为 IBM Plex Mono。
不依赖外部字体 CDN。页面标题约 22px，设置标题 20px，面板标题 16px。
正文和操作以 12–14px 为主；辅助信息 10–12px，保持对比度。
默认侧栏 196px，顶栏 52px，内容内边距 16–20px，面板圆角 10px。
主要控件 32px，导航项 36px；额外紧凑密度 28px。
卡片 padding 与 gap 统一 16px；Dialog 使用 p-4 / gap-4，表格单元格上下 8px、左右 12px。
以 shadcn 官方 Nova 默认尺度为基准，不恢复大尺寸 tile、开关或色块。
外观表单在足够宽时采用标签与控件同排，窄屏改为上下排列。
表格随数据横向溢出时局部滚动，不使整页横向溢出。
避免粗重分隔线、重阴影、渐变、浮雕按钮或多层卡片嵌套。

## shadcn 组成规则

使用官方 CLI 安装的 Radix / Nova、Tailwind 4、Lucide 图标。
组件主题通过 token 调整；导航的 navigation、设置的 appearance / swatch / segment 是正式变体。
表格使用 Table，表单使用 FieldGroup / Field / FieldLabel，选择使用 Select 或 ToggleGroup。
SelectItem 必须位于 SelectGroup；TabsTrigger 必须位于 TabsList。
弹窗必须有 DialogTitle 和 DialogDescription，并保留 Radix 的焦点管理。
恢复默认使用 AlertDialog。异步状态、错误、可重试操作必须可见。
按钮图标使用 `data-icon`，不在业务组件随意重设图标大小与颜色。

## 反馈与提示

复制、保存、收藏这类瞬时结果统一用右下角 toast，不在页面正文里追加“已复制”一类文字。
toast 由 `components/ui/toast.tsx` 的模块级 store 提供，`<Toaster />` 在应用根挂载一次，
页面任意模块可直接调用 `toast.success/error/info`，不需要 Provider。
同一句提示不会叠成两个；最多同时显示 3 条，成功 2.6 s、信息 3.6 s、错误 5.2 s 后自动消失。
成功与信息用 `status`，错误用 `alert`，都可以手动关闭；图标颜色分别取 success / destructive / primary token。
需要保留上下文的结果（例如写入文件的完整路径、上游返回的条数说明）仍留在页面里，不塞进 toast。

## 演示行为与响应式

创建、编辑、删除、分组整理和设置保存均作用于 localStorage 本地数据。
窗口详情仅打开详情说明，不能显示实际浏览器已启动或代理检测成功。
插件卡片的状态与按钮反映宿主真实结果；安装、授权与执行由桌面宿主处理。
桌面最小窗口 960 × 700；窄屏浏览器预览用于检查布局弹性。
700px 以下侧栏改为顶部导航，表格保留局部横向滚动，卡片单列排列。
动效只有短暂淡入与 4px 位移；系统减少动态效果始终优先。
每次变更检查桌面与窄屏、键盘、弹层、长文本及保存错误状态。
