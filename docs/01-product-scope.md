# 产品定位与范围

## 当前产品

Raccoon 面向使用多账户运营二手电商的 macOS / Windows 用户，采用紧凑、现代的后台界面。
Rust 统一管理窗口、接入、持久化操作和插件宿主。
首页表格通过内置浏览器、AdsPower、比特浏览器 Tabs 切换，不建立另一套 Profile 管理页面。

创建窗口会实际创建对应浏览器环境；接入已有外部环境只建立 Raccoon 业务关联。
打开、停止、详情、移出 Raccoon 与删除环境是独立操作。
窗口绑定创建后不可变，已保存的账号、代理与号码关系不随 Tab 切换而改变。
未安全实现的提供方配置根据能力声明禁用，不能以“通用”之名重置未知指纹。

## 页面

| 页面     | 职责                                                                      |
| -------- | ------------------------------------------------------------------------- |
| 窗口管理 | 提供方 Tabs、搜索和筛选、增删改查、批量创建、启停、快捷备注与账号号码联动 |
| 分组管理 | Raccoon 全局分组增删改查与全部接入窗口计数                                |
| 插件中心 | 商店安装、实际进程状态、详情与卸载；动态生成插件二级目录                  |
| 应用设置 | 外观、工作区、浏览器接入、内置内核与激活码、应用代理与更新                |

专用插件页面包括代理池、地址生成器、共享货源、AI 生图、Vinted 账号、Vinted 监控和 SIM8。
插件依赖自己的上游业务接口，Raccoon 不把配置保存解释为账号已登录或业务请求已成功。
具体交互见[页面文档](11-demo-pages.md)。

## 工程与数据边界

- 前端使用 React、TypeScript、Vite、Tailwind 4、shadcn/ui，Tauri 2 提供桌面能力。
- Rust 是 SQLite 唯一所有者，窗口、分组、接入、激活码和应用代理明文保存，不写 Keychain。
- 外观与工作区等界面偏好使用 localStorage；网页预览不能执行原生窗口命令。
- 内置浏览器经独立 Node 运行时启动，固定完整内核包、数据目录与随机种子。
- AdsPower 与比特浏览器经官方本机 API 接入，官方应用需已登录并开放 API；不替代官方套餐。
- 受信任的插件由独立 Node 进程执行，权限声明不是安全沙箱。
- Manager 仅作参考，不是运行时或数据库依赖；不引入 Python、FastAPI 或 Docker。

旧 IPC、DTO 别名、运行时读取和快照导入兼容已删除。
已有 SQLite 在启动时升级一次，正常读取只接受窗口 schema 2。
内置窗口加密迁移与同步仅接受 manifest 3，外部完整数据迁移使用厂商能力。

## 交互与验证

保留纸白与钴蓝、紧凑导航、轻分隔、Table 与 Dialog，不扩展企业权限或多租户功能。
同屏信息密度、键盘焦点、错误恢复与跨 Tab 请求竞态纳入质量要求。
空白安装不预置样例窗口，断线和未知状态不得冒充空数据或已停止。

最终用户不配置开发工具链或 `.env`；第三方浏览器接入仍需其官方应用。
源码实现与安装包、真实代理出口、厂商 API、Windows 和签名验证分别取证。
按约定不执行本地构建，实际检查与未验证项以[质量记录](09-quality-and-testing.md)为准。
