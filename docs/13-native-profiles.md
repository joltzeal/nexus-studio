# 原生 Profile 创建与试用

## 数据边界

窗口管理页的“创建窗口”直接创建原生 Profile，不再并列展示 localStorage 演示窗口。
创建后 Rust 在 Tauri 应用数据目录下创建 UUID 目录，并将配置写入 `nexus.sqlite`；
旧版本的 `profile.json` 会迁入 SQLite。
记录包含名称、内核通道、精确版本、官方包装层返回的二进制路径和可选无凭据代理服务器地址。
目录下 `user-data` 由 CloakBrowser 的持久上下文使用，包含 Cookie 等真实浏览器数据。
页面支持编辑原生配置和删除 Profile（包括浏览器数据）；旧演示窗口数据不自动迁移。
Profile 记录里没有账号字段：Vinted 账号由 `studio.vinted-accounts` 插件保存，
插件只记住 Profile 的 UUID，窗口名称仍只在主程序里。

## 创建与启动

从仓库根目录执行 `rtk proxy pnpm run desktop:dev`，已有 Nexus 前端预览服务
占用 1420 时会复用它。进入“窗口管理”，
在“创建窗口”填写名称、浏览器配置，并选择直连、HTTP/SOCKS5 手动代理或代理插件。
代理只允许不含账号密码的 `协议://主机:端口`，首次准备可能需要下载浏览器。
创建成功后列表显示实际内核版本；点击“打开”启动可见浏览器，
点击“停止”关闭。浏览器预览页无法调用原生后端。
首次创建可能需要下载内核，创建按钮会显示“正在准备内核”；
准备失败或超过 12 分钟会反馈错误且保留表单输入。创建命令返回已保存窗口，
界面直接加入列表，不再等待额外的列表刷新才结束保存状态。

包装层会按当前本机许可证状态选择可用二进制；本应用不会创建额外账号或修改许可。
在本机无有效密钥时，macOS 包装层当前取得的无密钥内核为 `145.0.7632.109`；
设置页保存有效授权后，新窗口会用它准备授权可用的最新内核；非 free 计划也可在创建时
填写 SDK 支持的精确版本。未配置密钥时使用包装层的无密钥可用版本。
创建后列表显示实际版本，不会自动升级已有 Profile。
启动前核对二进制 `--version` 与创建时的版本，若文件被更新、删除或替换则报错。
同一 Profile 不允许改用另一个版本；需要新内核时新建 Profile。
多个独立 Profile 可同时启动；相同 Profile 在启动、运行或停止期间不能重复启动。
Nexus 不硬编码一个会话的限制，CloakBrowser 根据当前密钥和计划裁决实际并发席位；
席位不足时启动失败并显示适配进程返回的错误，不自动换内核或回退直连。
窗口页展示本应用中已运行的 Profile 数量，不将它表述为许可席位数。

## 失败与恢复

目录已存在但 `profile.json` 缺失、损坏或绑定字段不一致时会报错，不自动重建。
新应用实例从磁盘读取绑定；正在运行的浏览器进程不会自动重连。
创建失败不应显示为创建成功；启动失败保留绑定以便排查，不转换为直连或别的版本。
手动关闭浏览器后列表刷新会回收运行状态。
窗口页支持选中窗口后加密导出、导入副本或显式覆盖，并通过窗口同步插件传到另一台设备。
导出前需要停止窗口；迁移期间不能启动、编辑或删除同一窗口。
导入保留精确内核版本、指纹种子和插件关联，不静默升级已有窗口。
迁移包另外记录本机清单中的完整内核包修订号和类型；
Chrome 显示版本相同但 SDK 包修订不同，不能视为同一个环境内核。
Cookie 与站点存储通过浏览器接口额外导出，解决仅复制数据库无法跨设备使用的问题。
迁移格式、事务与兼容边界见[窗口加密迁移](28-window-transfer.md)；
设备配对与网络边界见[窗口同步插件](29-window-sync-plugin.md)。
删除操作仍会永久删除该窗口目录。

## 分发边界

本阶段验证了 macOS 开发环境。适配器以仓库内构建的 JS 文件和本机 Node.js 启动；
正式安装包还须随应用分发受管 Node 运行时与 JS 依赖，并验证 macOS/Windows 路径、
签名、退出清理与内核授权。CloakBrowser JS wrapper 为 MIT 授权，官方二进制另有许可，
不得将本阶段的开发启动视为可对外分发的成品。
