# 页面与交互边界

## 当前页面

固定主导航为窗口管理、分组管理、插件中心和设置；插件二级导航根据已启用目录动态显示，
SIM8 与已有插件专用页面接入规则见[插件系统](06-plugin-system.md)。
保留紧凑的 shadcn 表格、侧栏和纸白钴蓝主题。
界面不使用“演示模式”“示例”等全局文案；对尚未接入的能力使用准确的“未连接”“待接入”状态。
桌面窗口页直接管理原生 Profile；网页预览不提供可保存的假窗口表单。
历史演示窗口仍留在 localStorage，但不再显示为原生窗口，见[原生 Profile](13-native-profiles.md)。

## 窗口管理

`src/features/spaces/spaces-page.tsx` 的原生窗口列表支持搜索名称、平台、备注与内核版本，
原生分组与关联账号状态筛选，并显示总数和运行中数量。
账号状态筛选包含正常、待验证、受限、封禁和未关联账号，可与搜索和分组组合使用。
账号插件不可用时不使用旧状态过滤窗口；账号资料缺失但仍有绑定的窗口不算未关联。
读取账号资料失败时显示暂不可用，并禁用关联、编辑和解绑，避免把未知关联当成空关联覆盖。
读取期间若账号保存成功，丢弃过期快照并重新读取，保留已保存的状态与手机号。
窗口固定按创建时间倒序；同一秒的记录按 SQLite 插入顺序倒序，旧记录缺失时间按 0 排在后面。
新建窗口立即插入列表顶部，搜索、分组、刷新、打开/停止和修改备注不会使用其他排序规则。
点击窗口名称下方的备注文字或“添加备注”进入行内输入框，焦点离开编辑区时自动保存，
Enter 或勾号也可保存，Esc 或叉号取消且不触发失焦写入。
显示文字、输入框与操作按钮统一为 22px 高；编辑、保存失败均不撑高表格行。
保存失败保留输入并以错误提示及输入框状态反馈，允许重试；留空保存会清除备注，最多 120 个字符。
备注使用独立原生命令保存，不提交名称、代理、分组或浏览器设置。
运行中的窗口也可改备注；迁移、资料恢复或应用安装更新期间由原生服务阻止保存。
创建、编辑在 Dialog 中完成；详情只读；删除经 AlertDialog 确认，保存失败保持弹窗并提示重试。
窗口字段包含名称、平台、备注、代理方式、GeoIP、时区、语言、尺寸、指纹种子及起始地址。
名称最多 40 字，备注最多 120 字；手动代理地址只接受无凭据的 HTTP/SOCKS5 主机与端口。
代理方式分三种：直连、手动填写、代理插件。选择代理插件时下拉只列出运行中的
`proxy.provider` 插件，没有运行中的插件会提示先到插件中心安装代理插件并选择默认代理；
代理插件与手动地址互斥，保存时由 Rust 侧校验。
不保存账号、密码、令牌或代理密码。详情中显示的代理是配置记录，不表示网络出口已生效。
在桌面应用中，窗口创建即准备内核并写入原生 Profile 记录；编辑不更换已有内核或指纹种子。
新建和批量创建默认请求最新稳定内核，也可从本机清单选择已安装的完整包版本；
其他版本可先到内核设置下载，已有窗口不提供版本切换。
尚未配置激活码时表单提示前往「应用设置 → 激活码」，创建按钮不可用。
后端仍独立校验激活码，不能通过省略前端状态绕过。
创建成功直接显示新窗口；内核准备超时会保留表单并提示重试，不会无限显示保存状态。
页面标题右侧的“刷新”同时重新读取窗口、分组和激活码状态，刷新期间禁用按钮，失败显示错误且保留已有列表。
列表和详情不启动浏览器，“打开”显式启动，“停止”结束会话；删除会清理浏览器数据。
使用代理的窗口启动前仍检测代理，宿主确认窗口运行后自动关闭检测弹窗。
启动失败或运行状态尚未确认时保留对应结果；重新读取确认运行以及迟到的启动请求完成后
确认运行也会关闭弹窗，不能只凭代理检测通过就当作窗口已打开。
点击打开后，对应行在代理检测、原生启动及等待启动结果确认期间使用主题强调色高亮，
同时显示“检测代理中”“启动中”或“状态待确认”；停止窗口不会使用启动高亮。
代理阻断、明确启动失败或确认运行后退出高亮；启动请求超时后仍保留高亮，
直到后续读取确认运行或确认请求已结束且窗口未运行。高亮不闪烁、不改变行高，适配浅色和深色主题。
“Vinted 账号”列显示已关联账号、状态与可复制的高亮手机号；未关联时提供“添加账号”。
封禁账号名称和状态使用红色语义样式，编辑状态后同步更新所有关联行及当前筛选结果。
手机号旁提供直接解绑，成功后清空该账号的手机号和短信接码链接，所有关联窗口同步更新；
账号其他资料、窗口关联和 SIM8 号码池保持不变，失败保留原值并允许重试。
快捷关联弹层使用“选择已有 / 新建账号”两个 Tabs，列表与新建表单不再上下堆叠。
手机图标弹层使用“验证码 / 号码池 / 编辑链接”三个 Tabs，手机号和接码链接属于账号，
同一账号关联的窗口共享这些资料；选号直接保存到账号，只改接码链接时保留原手机号。
可以在弹层中读取已保存链接的验证码、查看原文和复制结果；未保存的链接草稿不参与取码。
号码池标记当前账号与其他占用账号，查询失败明确提示占用未知，不将未知误写为未使用。
每行操作区最右侧的 `…` 下拉菜单提供“关联账号 / 更换账号”和“解除关联”，
关联在 Dialog 里从账号池中选择，可搜索账号与备注。
一个窗口最多关联一个账号；把同一个账号关联到第二个窗口时先弹 AlertDialog，
写明它已经关联到哪些窗口、确认后会共用同一账号，确认后才写入。

## 分组管理

当前分组页只解释原生分组尚未接入，旧 localStorage 分组不冒充真实窗口分组。

## 插件中心

一张紧凑表格，列为插件（图标、名称、标识）、能力、版本、状态与操作。
状态只有“未安装 / 运行中 / 启动中 / 重试中”，全部来自宿主检查；
安装即启用并授予 manifest 声明的全部能力，应用启动时宿主会把已安装插件全部拉起，
进程退出后自动重启，因此没有停用、重启或授权弹窗。
操作只有“安装”、清单详情（`i` 图标）与卸载；卸载经 AlertDialog 确认。
表格上方只保留数量与运行中数量，页面没有说明性文案，也没有演示占位。
非桌面环境用同一张表格展示随仓库提供的 manifest 声明，状态标注“仅桌面应用”。

## 代理池

`src/features/proxy/proxy-pool-page.tsx` 通过插件宿主调用 `studio.proxy-pool` 的方法，
布局对齐参考实现的代理管理页：标题与操作行、筛选条、表格面板与分页。

- 操作行：新增代理、批量添加、检测选中（按协议选择）、复制 URL、订阅、删除选中、
  刷新与插件配置。未选中任何行时，依赖选择的操作保持禁用。
- 筛选条直接映射 `proxy.list` 参数：关键字、协议、分组（含未分组）、启用状态，
  以及“更多筛选”里的是否代理 / VPN / 数据中心与风险分区间；筛选由插件完成，
  页面不做二次过滤。关键字输入有 250 ms 防抖。
- 表格列：勾选、名称、分组、支持协议、主机地址、端口、用户名、密码、状态、
  检测信息、IP 质量与操作。分组、协议、用户名、密码、检测与质量列可隐藏；
  排序只作用于当前页，与参考实现一致。
- 检测信息与 IP 质量是悬停浮层：前者展示检测结果、协议、耗时、出口 IP 历史与属地；
  后者展示风险类型、评分（100 − 风险分）、置信度与来源。无数据时说明原因，不显示 0 分。
- 行操作菜单：复制代理 URL（多协议时二级选择）、按协议检测、设为默认代理、编辑、删除。
- 分页用插件的 `limit`/`offset` 与 `total`；每页 10/50/100/200/500，删除当前页最后一条会回退一页。
- 侧栏面板：新增/编辑表单、批量添加（URL 与 Decodo 两种）、复制 URL、Clash 订阅与插件配置。
  密码只写不读；复制出的 URL 不含密码，因为宿主不读取插件私有目录里的密码。
- 新增代理时把整条链接粘进“主机地址”会就地识别，两种常见写法都支持：
  `socks5://user:pass@host:port` 与 `socks5://host:port:user:pass`（后者密码可含冒号）。
  识别后写入协议、主机、端口、用户名与密码，并在字段下方说明命中的格式与是否含认证信息；
  确认行只显示主机与端口，不回显密码。未写名称时用主机名作为默认名称。
  该识别属于页面便利，插件侧的 `proxy.import` 仍只接受 `scheme://user:pass@host:port`。
- 宿主不可用、插件未安装或未运行时，页面给出对应说明与启用/重启入口，不展示伪造的库存。
- 默认代理为空时，表格面板标题行提示“未设置默认代理，窗口启动会被阻断”，
  不暗示会自动直连；该提示只在配置读取成功后出现，未读到配置时不猜。

## 地址生成器

`src/features/addresses/address-page.tsx` 通过插件宿主调用 `studio.address-generator` 的
`address.*` 方法，页面本身不生成地址，也不保存地址。

- 工具栏：国家、城市、生成数量（1–50）与「公开地址 / 地图选点」切换；
  生成按钮只在公开地址模式下出现。国家来自 `address.catalog`，切换国家时城市重置为该国第一个城市。
- 公开地址：`address.generate` 从 OpenStreetMap 公开地址取候选，同一国家与城市命中 15 分钟缓存时
  提示“会得到同一批候选”。取到的条数少于请求数时如实说明，不补齐、不编造。
- 地图选点：需要先保存 Google Maps Key，未保存时提示并给「填写地图 Key」入口；
  在画布上点选后由页面用 Geocoding 解析，再交给 `address.profile` 分配姓名与 username。
  解析失败、Key 无效或脚本加载失败分别给出对应文案，不显示空结果冒充成功。
- 结果卡片：姓名、username、完整地址，以及街道地址、城市、邮编、州/地区、名、姓、username
  七个可单独复制的字段，另有「复制资料」与「复制 username」；
  卡片底部链接回该地址的 OpenStreetMap 页面。所有复制都经 `copyText`，失败时提示剪贴板权限。
- 结果区操作：复制全部、复制 CSV、写入 CSV 文件（写到插件 `exports` 目录，成功后提供「复制文件路径」）、清空结果。
  生成会替换当前结果；重复地址按地址键去重并提示，超过 50 条要求先清空。
- 宿主不可用、插件未安装、插件未启用或进程失败时，页面分别给出说明与启用/重启入口；
  生成结果只存在页面状态里，刷新即消失，不写入插件存储。

## 共享货源

`src/features/supply/supply-page.tsx` 通过插件宿主调用 `studio.shared-supply` 的 `supply.*` 方法。
页面不缓存商品数据，切换分类、翻页或切分区都会重新请求。

页面最外层是一个 Card，标题、分区与操作行固定在卡内顶部，内容区在剩余高度里滚动；
整页（含窗口本身）不出现滚动条，滚动只发生在卡片内容区。

- 分区：分类商户、搜索商品、以图搜图、我的收藏；右上角是视图切换（列表 / 瀑布流）与刷新按钮，
  两者放在同一个右对齐的操作组里。
- 分类商户：分类按钮来自 `supply.catalog`；左栏商户列表（每页 80），右栏该商户商品（每页 30）。
  左栏固定不动、不自带高度上限，只有右栏商品区滚动；商户仍用翻页按钮切换。
  切换分类会清空选中商户并回到第一页；加载中显示“正在加载…”，加载完但为空才说“暂无商户 / 暂无商品”。
- 右栏商品是触底加载：滚到底部的哨兵进入视野就请求下一页并追加，不再有翻页按钮；
  追加时按商品 id 去重，避免商户在两次请求之间上新造成重复。到底后显示“已经到底了”。
- 搜索商品：关键词最多 100 字，提交后按页请求（每页 15），同样是触底加载并追加。
- 以图搜图：接受 JPEG / PNG / WebP，≤ 5 MB，最短边 ≥ 100、最长边 ≤ 8000 像素；
  页面先用 canvas 纠正方向并转成 JPEG（质量 0.88）再提交，因此上游只收到 JPEG。
  校验失败直接提示原因，不发起请求。
- 商品详情：图片主图与缩略图切换、价格、描述、发布时间、图片数、商户标识；
  可收藏 / 取消收藏，可复制标题、图片链接与整份商品资料。复制结果走 toast。
- 商户头像、商品缩略图和详情图片统一由插件下载并分块交给页面，以 Blob 显示，继承应用代理；
  失败显示原因，详情主图支持重试，页面刷新也会重新加载。重复点击当前分类或商户不清空结果。
- 我的收藏：列表来自插件私有存储，可复制 CSV（含 BOM，Excel 直接可读）与收藏标题；
  存储不可持久化时标注“仅本次运行”。
- 宿主不可用、插件未安装或进程未就绪时统一用占位说明，没有启用或重启入口；
  卡片标题栏只有标题与操作组，不再放说明文案。

## AI 生图

`src/features/ai-image/ai-image-page.tsx` 通过插件宿主调用 `studio.ai-image` 的 `image.*` 方法。
页面与共享货源同构：最外层一个 Card，内容区在可用高度内滚动，整页不出滚动条。
插件实现细节见 [AI 生图插件](22-ai-image-plugin.md)。

- 主页即生成记录：按时间倒序的表格，列为预览、内容（标题或提示词）、状态、模型、时间与查看。
  顶部按“全部 / 生成中 / 已生成 / 失败”筛选，每页 10 条，翻页重新请求。
  有记录处于生成中或成片识图中时每 2.5 s 轮询一次，全部结束后停止轮询。
- 新建生成：可上传 1–6 张参考图（有参考图即走改图，没有则走文生图），
  选择服务商、尺寸（1024×1024 / 1024×1536 / 1536×1024 / 由模型决定）与张数（1–4）。
  本地参考图先纠正方向、限制最长边 1536 并转成 JPEG，再分块上传；
  货源页面带入的远程图片由插件下载，上传成功后通过插件文件 API 显示 Blob 预览。
- 提示词：提供自由提示词和 10 类共 100 个原创场景，覆盖欧美普通家居、庭院、衣物鞋包等生活环境。
  可按分类或中英文关键词筛选，筛选不会清空已选项；可展开英文场景内容。
  选预设后可添加自定义约束，保留原始标识、成色、瑕疵与使用痕迹。
  自定义内容最多 12000 字符，超出时保留原文并阻止提交，不静默截断。
- 独立识图：在生成弹窗选择单独配置的服务商与识图模型，默认识别第一张参考图，也可指定某一张。
  只有选中图片发给识图模型，观察结果用于生图与文案；改图仍使用全部已上传参考图。
  识图失败明确报错并停止本次生成；未启用时保留原有流程。
- 智能场景：先识别商品类型与材质，推荐现有场景并规划 1–4 个不同视角。
  展示推荐理由和不确定项，允许修改场景、公共提示词与各视角提示词，确认后才生成。
  一张参考图也可生成多张场景图；生成详情显示逐视角进度与结果，
  部分失败保留成片，重试只补未完成视角。接口与恢复边界见[智能场景规划](31-ai-scene-planning.md)。
- 生成详情：左侧是滑动对比——一条分割线把参考图与生成图叠在一起，拖动或按方向键移动，
  没有参考图时退化为单图；多张输出用缩略图切换，多张参考图单独列一行。
  右侧是标题、描述、提示词（均可复制）与提交时间、耗时、方式、预设、服务商、模型、
  尺寸、张数、参考图与输出数量。失败记录显示错误原文，文案失败单独提示且不影响图片。
  已生成的组图默认选中第一张，点击缩略图后可“识别当前成片”；仅发送选中成片，
  不重新生成图片或改写原文案。保存识图模型、图片、结果或错误，失败可按原选择重试。
- 模型配置：服务商列表可测试、编辑、删除；表单含名称、类型（OpenAI 官方 / OpenAI 兼容）、
  接口地址、API Key、生图模型、识图模型、文案模型与“文案模型可直接读取成片”开关。
  允许仅配置识图模型的服务商；独立识图不自动复用文案模型，旧记录不会自动新增识图调用。
  接口地址只接受 http(s) 且不能带凭据，缺版本段时自动补 `/v1`。
  API Key 按明文存在插件私有目录（0600），页面只显示末四位，不提供回读。
- 导出：把输出复制到插件 `exports/` 目录并给出可复制的路径；桌面端没有保存对话框，
  因此不承诺浏览器下载。
- 商品联动：Vinted 商品图库选择最多 6 张图片后进入生成弹窗，保留商品来源与选图顺序。
  图片先由监控插件通过采集代理下载，再按原始字节上传给 AI 插件；不会交给 WebView 直接下载。
  参考图传输失败保留选择并支持重试或移除，尚未完成时禁止提交生成。
  来源商品标识持久化到生成记录，可在商品页按来源查看分页历史；查看历史不会自动调用模型。
- 宿主不可用、插件未安装或进程未就绪时统一用占位说明，没有启用或重启入口。

## Vinted 账号

`src/features/accounts/accounts-page.tsx` 通过插件宿主调用 `studio.vinted-accounts` 的
`vinted.accounts.*` 方法。插件实现细节见 [Vinted 账号池插件](24-vinted-accounts-plugin.md)。

- 主页是账号表格：账号（含备注或主页链接）、登录方式、手机号、状态、关联窗口数、创建时间与编辑 / 删除。
  封禁账号的名称与状态使用红色标识；创建时间显示本地日期和时间，默认按创建时间倒序。
  顶部保留“刷新 / 导入 / 新增账号”，可按关键词、状态、登录方式、是否有手机号和是否关联窗口筛选。
  关联窗口数只显示数量，窗口名属于窗口页。
- 分页默认每页 20 条，可选 50 或 100 条；筛选和每页条数变化回到首页，
  删除或刷新后页码不越界。表头全选只作用于当前页，跨页和跨筛选勾选保留，
  批量创建使用所有已选账号，仍受每批 100 个的既有限制。
- 手机号旁可复制或直接解绑，解绑同时清空短信接码链接；
  成功后旧短信验证码与迟到的旧请求结果不再显示，失败保留原资料，允许重试。
- 新增与编辑在 Dialog 里完成：登录方式（邮箱 / Google / Apple / Facebook）、账号、密码、
  手机号、主页链接、邮箱接码地址、手机接码地址、状态与备注。登录方式与账密必填，
  密码默认隐藏，可点眼睛图标显隐；其余字段留空合法。
- 导入：选 CSV 或 XLSX，表头可用中文或英文，列顺序可以调换；没有表头时按模板列序读取。
  导入后回显“共 N 行 · 新增 / 更新 / 跳过”和出错行号与原因，不会只报“导入成功”。
  同一登录方式下的同一账号视为同一条记录，重复导入是更新。
- 模板：导入弹窗里提供“下载 CSV 模板”与“下载 XLSX 模板”，CSV 带 BOM，Excel 直接可读。
- 删除经 AlertDialog 确认，会同时解除该账号与所有窗口的关联。
- 宿主不可用、插件未安装或进程未就绪时统一用占位说明，没有启用或重启入口。

## Vinted 监控

`src/features/vinted-monitor/vinted-monitor-page.tsx` 通过插件宿主调用
`studio.vinted-monitor` 的 `vinted.*` 方法。插件实现细节见
[Vinted 监控插件](23-vinted-monitor-plugin.md)。页面与另两个插件页同构：最外层一个 Card，
内容区在可用高度内滚动，整页不出滚动条。

- 两个页签为“URL 监控”和“商品表格”，右上角“采集代理”管理插件自己的代理，
  布局、字段、筛选与操作参考 `nexus-cart` 的 `vinted-monitors`、`vinted-items`。
  监控和商品均支持显示列、刷新、每页数量与页码切换；RPC 页码从 0 开始。
- 监控表格包含名称、监控类型、URL、代理、间隔、最多页数、每页商品数、状态、创建时间、
  最近采集状态、商品数和操作菜单。读取完成后间隔 5 s 刷新，避免慢请求相互覆盖。
  点击商品数进入对应监控的商品筛选；暂停的监控不能手动采集。
- 新增与编辑使用右侧 Sheet：名称、监控 URL、采集代理、采集间隔、分页策略和启用状态。
  URL 失焦时由插件解析校验；识别到用户衣柜时提供 20 页 × 96 件的推荐值。
  触达页数上限只表示扫描不完整，不表示全部商品已被采集。
- 采集代理可新增、编辑、删除并设置插件默认，支持 HTTP、HTTPS、SOCKS5、SOCKS5H 和链接填入。
  编辑时密码明确区分保留、替换、清除；保存失败不关闭表单。
  监控可以单独指定代理或继承插件默认，插件未配置默认时继承应用网络。
  已指定代理失效时阻断请求，不回退其他网络；这些代理不写入代理池或应用设置。
- 采集记录使用分页表格，显示开始与结束、状态、发现、新增、更新、卖家失败、跳过、失败、
  扫描页数及触达上限状态。运行期间轮询，读取失败与空记录分别反馈。
- 商品表格包含星标、核查状态、图片、标题、价格、点赞、浏览、卖家、来源国家、来源 ID、
  采集时间、原商品链接与操作。默认按采集时间倒序，支持点赞升降序、零值和空值筛选，
  并可按监控、核查状态、星标、来源 ID、关键词筛选；后端先筛选排序再分页。
- 图片与卖家头像由监控插件下载并经分块 RPC 传递，以 Blob 展示；详情主图支持重试。
  点击标题查看归档快照、卖家资料和核查备注；人工标记仍在售、已售出、待核查或忽略。
  完整、可比的采集发现商品消失时只标记待核查，不推断为已售出。
- 卖家弹层包含评分、关注数、商品数、认证和资料采集状态；“监控卖家”复用已有监控，
  新建时继承来源监控的代理与间隔。已暂停的卖家监控明确显示暂停。
- 图库最多选 6 张送入 AI 生图；“商品生成记录”仅查询该商品关联记录。
  AI 插件未运行时禁止联动，旧 AI 插件不支持来源字段时明确提示更新。
- 删除商品需要确认，后续采集不会重新加入该商品；删除监控保留归档商品。
  删除失败保留确认框并展示原因。
- 宿主不可用、插件未安装或进程未就绪时显示实际门禁。旧监控插件缺少新方法时
  提示更新并不挂载新接口页面，避免使用不兼容的创建、分页或代理操作。

## 应用设置

外观页支持主题、强调色、密度和减少动态效果；工作区页管理显示名称；
CloakBrowser 页提供桌面授权状态、校验保存和删除；关于页显示版本、本地资料管理、存储来源及未连接的浏览器状态。
设置保存失败反馈真实错误，不冒充引擎操作结果。

## 存储与迁移

历史演示窗口与分组沿用 `nexus.demo.workspace.v1` 键，内部 schemaVersion 为 2；
真实窗口改走 Rust Profile 目录，插件状态以宿主为准，旧演示数据不会自动迁移。
原有 v1 记录读取时补充默认窗口配置，直到用户保存才写回 v2；不会清除旧记录。
读取旧记录时去除名称中的“示例 / 演示”前缀和已知的旧版占位备注；其他资料保留。
没有存储数据时显示空窗口与空分组。格式不正确的内容保持原始字节并报错，
不能以空白状态覆盖它。偏好仍使用 `nexus.preview.preferences.v1`。
