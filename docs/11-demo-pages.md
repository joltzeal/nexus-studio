# 页面与交互边界

## 当前页面

主导航为窗口管理、分组管理、插件中心、代理池、地址生成器、共享货源和应用设置。保留紧凑的 shadcn 表格、侧栏和纸白钴蓝主题。
界面不使用“演示模式”“示例”等全局文案；对尚未接入的能力使用准确的“未连接”“待接入”状态。
桌面窗口页直接管理原生 Profile；网页预览不提供可保存的假窗口表单。
历史演示窗口仍留在 localStorage，但不再显示为原生窗口，见[原生 Profile](13-native-profiles.md)。

## 窗口管理

`src/features/spaces/spaces-page.tsx` 的原生窗口列表支持搜索名称、平台、备注与内核版本，并显示总数和运行中数量；原生分组筛选尚未接入。
创建、编辑在 Dialog 中完成；详情只读；删除经 AlertDialog 确认，保存失败保持弹窗并提示重试。
窗口字段包含名称、平台、备注、代理方式、GeoIP、时区、语言、尺寸、指纹种子、起始地址及创建时可选内核版本。
名称最多 40 字，备注最多 120 字；手动代理地址只接受无凭据的 HTTP/SOCKS5 主机与端口。
代理方式分三种：直连、手动填写、代理插件。选择代理插件时下拉只列出运行中的
`proxy.provider` 插件，没有运行中的插件会提示先到插件中心启用并选择默认代理；
代理插件与手动地址互斥，保存时由 Rust 侧校验。
不保存账号、密码、令牌或代理密码。详情中显示的代理是配置记录，不表示网络出口已生效。
在桌面应用中，窗口创建即准备内核并写入原生 Profile 记录；编辑不更换已有内核或指纹种子。
创建成功直接显示新窗口；内核准备超时会保留表单并提示重试，不会无限显示保存状态。
页面标题右侧的“刷新”同时重新读取窗口和分组，刷新期间禁用按钮，失败显示错误且保留已有列表。
列表和详情不启动浏览器，“打开”显式启动，“停止”结束会话；删除会清理浏览器数据。

## 分组管理

当前分组页只解释原生分组尚未接入，旧 localStorage 分组不冒充真实窗口分组。

## 插件中心

能力卡分为两组。“可安装”列出宿主发现到的插件包，展示名称、版本、能力标识、
网络域名、密钥槽与存储范围，并按真实状态显示“可安装 / 已安装未启用 / 运行中 / 进程失败”；
启用前的授权弹窗列出可授权能力、域名、密钥槽与存储范围，确认后才启动进程。
已安装插件提供停用、重启、卸载与清单查看；插件密码由插件自行保存，宿主不提供通用密钥槽写入命令。
“演示占位”保留图片、平台账号、接码和环境配置四个能力入口，状态为“待接入”。
非桌面环境不显示安装与启用按钮，只展示随仓库提供的 manifest 声明，并标注“仅桌面应用”。
页面不把安装成功描述为运行中，进程失败会显示真实错误文本。

## 代理池

`src/features/proxy/proxy-pool-page.tsx` 通过插件宿主调用 `studio.proxy-pool` 的方法，
布局对齐参考实现的代理管理页：标题与操作行、筛选条、表格面板与分页。

- 操作行：新增代理、批量添加、检测选中（按协议选择）、复制 URL、订阅、删除选中、
  刷新与插件配置。未选中任何行时，依赖选择的操作保持禁用。
- 筛选条直接映射 `proxy.list` 参数：关键字、协议、分组（含未分组）、启用状态，
  以及“更多筛选”里的是否代理 / VPN / 数据中心与风险分区间；筛选由插件完成，
  页面不做二次过滤。关键字输入有 250 ms 防抖。
- 表格列：勾选、名称、分组、支持协议、主机地址、端口、用户名、密码、状态、
  检测信息、IP 质量与操作。分组、协议、用户名、密码、检测与质量列可隐藏；
  排序只作用于当前页，与参考实现一致。
- 检测信息与 IP 质量是悬停浮层：前者展示检测结果、协议、耗时、出口 IP 历史与属地；
  后者展示风险类型、评分（100 − 风险分）、置信度与来源。无数据时说明原因，不显示 0 分。
- 行操作菜单：复制代理 URL（多协议时二级选择）、按协议检测、设为默认代理、编辑、删除。
- 分页用插件的 `limit`/`offset` 与 `total`；每页 10/50/100/200/500，删除当前页最后一条会回退一页。
- 侧栏面板：新增/编辑表单、批量添加（URL 与 Decodo 两种）、复制 URL、Clash 订阅与插件配置。
  密码只写不读；复制出的 URL 不含密码，因为宿主不读取插件私有目录里的密码。
- 新增代理时把整条链接粘进“主机地址”会就地识别，两种常见写法都支持：
  `socks5://user:pass@host:port` 与 `socks5://host:port:user:pass`（后者密码可含冒号）。
  识别后写入协议、主机、端口、用户名与密码，并在字段下方说明命中的格式与是否含认证信息；
  确认行只显示主机与端口，不回显密码。未写名称时用主机名作为默认名称。
  该识别属于页面便利，插件侧的 `proxy.import` 仍只接受 `scheme://user:pass@host:port`。
- 宿主不可用、插件未安装或未运行时，页面给出对应说明与启用/重启入口，不展示伪造的库存。
- 默认代理为空时，表格面板标题行提示“未设置默认代理，窗口启动会被阻断”，
  不暗示会自动直连；该提示只在配置读取成功后出现，未读到配置时不猜。

## 地址生成器

`src/features/addresses/address-page.tsx` 通过插件宿主调用 `studio.address-generator` 的
`address.*` 方法，页面本身不生成地址，也不保存地址。

- 工具栏：国家、城市、生成数量（1–50）与「公开地址 / 地图选点」切换；
  生成按钮只在公开地址模式下出现。国家来自 `address.catalog`，切换国家时城市重置为该国第一个城市。
- 公开地址：`address.generate` 从 OpenStreetMap 公开地址取候选，同一国家与城市命中 15 分钟缓存时
  提示“会得到同一批候选”。取到的条数少于请求数时如实说明，不补齐、不编造。
- 地图选点：需要先保存 Google Maps Key，未保存时提示并给「填写地图 Key」入口；
  在画布上点选后由页面用 Geocoding 解析，再交给 `address.profile` 分配姓名与 username。
  解析失败、Key 无效或脚本加载失败分别给出对应文案，不显示空结果冒充成功。
- 结果卡片：姓名、username、完整地址，以及街道地址、城市、邮编、州/地区、名、姓、username
  七个可单独复制的字段，另有「复制资料」与「复制 username」；
  卡片底部链接回该地址的 OpenStreetMap 页面。所有复制都经 `copyText`，失败时提示剪贴板权限。
- 结果区操作：复制全部、复制 CSV、写入 CSV 文件（写到插件 `exports` 目录，成功后提供「复制文件路径」）、清空结果。
  生成会替换当前结果；重复地址按地址键去重并提示，超过 50 条要求先清空。
- 宿主不可用、插件未安装、插件未启用或进程失败时，页面分别给出说明与启用/重启入口；
  生成结果只存在页面状态里，刷新即消失，不写入插件存储。

## 共享货源

`src/features/supply/supply-page.tsx` 通过插件宿主调用 `studio.shared-supply` 的 `supply.*` 方法。
页面不缓存商品数据，切换分类、翻页或切分区都会重新请求。

- 分区：分类商户、搜索商品、以图搜图、我的收藏；右上角可切换列表 / 瀑布流视图并刷新。
- 分类商户：分类按钮来自 `supply.catalog`；左栏商户列表（每页 80），右栏该商户商品（每页 30）。
  切换分类会清空选中商户并回到第一页；加载中显示“正在加载…”，加载完但为空才说“暂无商户 / 暂无商品”。
- 搜索商品：关键词最多 100 字，提交后按页请求（每页 15），翻页重新请求。
- 以图搜图：接受 JPEG / PNG / WebP，≤ 5 MB，最短边 ≥ 100、最长边 ≤ 8000 像素；
  页面先用 canvas 纠正方向并转成 JPEG（质量 0.88）再提交，因此上游只收到 JPEG。
  校验失败直接提示原因，不发起请求。
- 商品详情：图片主图与缩略图切换、价格、描述、发布时间、图片数、商户标识；
  可收藏 / 取消收藏，可复制标题、图片链接与整份商品资料。复制结果走 toast。
- 我的收藏：列表来自插件私有存储，可复制 CSV（含 BOM，Excel 直接可读）与收藏标题；
  存储不可持久化时标注“仅本次运行”。
- 宿主不可用、插件未安装、未启用或进程失败时，分别给出说明与启用/重启入口；
  商品资料来自第三方公开接口，页面明确说明不代表可直接下单。

## 应用设置

外观页支持主题、强调色、密度和减少动态效果；工作区页管理显示名称；
CloakBrowser 页提供桌面授权状态、校验保存和删除；关于页显示版本、本地资料管理、存储来源及未连接的浏览器状态。
设置保存失败反馈真实错误，不冒充引擎操作结果。

## 存储与迁移

历史演示窗口与分组沿用 `nexus.demo.workspace.v1` 键，内部 schemaVersion 为 2；
真实窗口改走 Rust Profile 目录，插件状态以宿主为准，旧演示数据不会自动迁移。
原有 v1 记录读取时补充默认窗口配置，直到用户保存才写回 v2；不会清除旧记录。
读取旧记录时去除名称中的“示例 / 演示”前缀和已知的旧版占位备注；其他资料保留。
没有存储数据时显示空窗口与空分组。格式不正确的内容保持原始字节并报错，
不能以空白状态覆盖它。偏好仍使用 `nexus.preview.preferences.v1`。
